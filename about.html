About

Paste a substitution cipher (cryptogram) and CipherLoop-S, a 241,758-parameter model, decrypts it. Inference runs locally on your browser! The site keeps an anonymous count of ciphers decoded. This site is non-commercial.

Attribution

CipherLoop builds on ALICE by Jeff Shen and Lindsay M. Smith [1]. The model code in cipherloop.js is adapted from their code at github.com/al-jshen/alice, Copyright (c) Jeff Shen and Lindsay M. Smith, licensed under the Apache License, Version 2.0.

The model weights were trained on QUOTES500K [16], which its authors released for educational and research purposes. No dataset text is included in this site.

The page's visual style is modeled on Autograder.io's open-source frontend (ag-website-vue, LGPL-3.0). No code from it is included; this site is not affiliated with Autograder.io or the University of Michigan.
